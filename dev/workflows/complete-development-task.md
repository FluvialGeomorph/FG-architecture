# Complete a development task

1. Re-read the request, applicable `AGENTS.md`, scoped Git state, and relevant durable context.
2. Confirm implementation matches the authorized scope and preserves unrelated work.
3. Run proportionate tests, contract validation, link checks, and repository-specific checks.
4. Review failures and unresolved uncertainty; do not hide waived or unavailable checks.
5. Classify whether the task changed:
   - goals or scope;
   - architecture or capability boundaries;
   - an accepted decision;
   - a schema or interface contract;
   - a repeatable workflow;
   - feature behavior;
   - user-facing behavior; or
   - active work state.
6. Update every required durable or user-facing destination from the [promotion matrix](../governance/artifact-standard.md).
7. Recheck authority, duplication, links, evidence labels, and information safeguards.
8. Review Git status and diff; confirm only authorized repositories changed.
9. If meaningful work remains, update one current checkpoint for the work stream. Otherwise, archive or remove any obsolete checkpoint.
10. Report changes, decisions, uncertainty, verification, and next steps. Do not commit, release, or deploy unless explicitly authorized.
