# Architecture decision records

This directory preserves consequential organization choices, rationale, alternatives, and consequences. Add an ADR when a choice constrains future work; do not use ADRs for status, minor edits, or current-state summaries. Update an accepted ADR only for corrections or status/supersession metadata; normally supersede it with a new ADR. Maintainers accept decisions, and accepted records are permanent history. Architecture documents describe the resulting current state.

Use [template.md](template.md). Historical ADRs are not rewritten merely because the template later evolves.
