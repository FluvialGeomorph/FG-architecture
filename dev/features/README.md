# Cross-repository features

This directory owns durable design documentation for a cohesive capability narrower than the whole system that spans repository boundaries, schemas, or workflows. Put organization-level behavior, participating owners, contracts, and verification strategy here; do not duplicate member implementation detail, whole-system architecture, or transient plans. Update it when the cross-repository capability design changes. Participating maintainers approve it; member repositories remain authoritative for implementation. ADRs record choices and schemas define exact contracts.

No version 0.1 cross-repository feature record is needed yet.
