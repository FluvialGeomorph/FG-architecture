# Scripts

This directory is reserved for proven, reusable maintenance or validation automation specific to this architecture standard. Do not add speculative scripts, one-off task helpers, generated output, or member-repository build logic. Add a script only after a repeatable need, interface, safety boundary, and verification method are understood. Maintainers own scripts through normal review; workflows describe when they run and schemas define any maintained outputs.

Version 0.1 intentionally contains no permanent scripts.
